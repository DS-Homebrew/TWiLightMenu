# AI Usage Guidelines

Due to the rise of AI usage in development projects, these guidelines have been written to ensure AI is used in a fair way, along with keeping a majority of **TW**i**L**ight Menu++ human-made.

We do not recommend using an AI tool (such as ChatGPT, OpenAI, Claude, etc.) for your feature or bug fix unless you absolutely have to.    
In the event that you do, please read the following before opening a PR.

1. You must already be an experienced developer.
2. You must already have written most of the code by hand. Do not use AI to generate the entirety or a large part of the code.
3. Do not include AI-generated/modified images or audio.
4. You must manually refine the code for your feature. In other words, please correct any mistakes you can find that the AI left in.
5. Please test out the feature or bug fix to ensure it works properly.
6. You must state that AI has been used in your PR (ex. `This has been implemented with help from AI. I have reviewed and tested the code.`) under `What's changed?`.
